# Olá 👋, eu sou o Leonardo!

🚀 **Desenvolvedor Full Stack | Java & Spring Boot | Angular**

Sempre gostei de tecnologia e sempre tive a curiosidade de entender como tudo funcionava. Essa busca constante me fez enxergar a programação não apenas como linhas de código, mas como uma forma de solucionar problemas reais, construir soluções do zero e criar ferramentas que facilitem o dia a dia das pessoas.

Sou formando em **Análise e Desenvolvimento de Sistemas pela FEMA** e atuo como **Desenvolvedor Full Stack**, projetando sistemas de ponta a ponta, desde a construção de APIs robustas no back-end até interfaces modernas e responsivas no front-end.
